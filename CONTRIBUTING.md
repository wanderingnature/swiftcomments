# Contributing

Contributions are welcome: bug reports, fixes, and improvements to the method
or the code. Issues need nothing more than a clear description. Pull requests
need the agreement below.

## Why there is an agreement

The code is offered under the AGPL-3.0-or-later and, separately, under
commercial licences. Nicholas Holshouser can offer the commercial licence only
for code he has the right to license that way. The agreement gives him that
right for your contribution. You keep the copyright in your work, and the
contribution stays available to everyone under the AGPL.

## How to agree

Include this line in the description of each pull request:

    I have read and agree to the Contributor Agreement in CONTRIBUTING.md.

A pull request without it will not be merged.
